03 / Command Center

Your super receiver number

Authorize a phone number you control to send protected instructions to your AI bot, including an approved email action. Arbitrary shell commands and AI-generated actions are blocked.

Controller security

Requires at least one authorized phone number and a separate command PIN.

Never use your WhatsApp, email, or VPS password. The PIN is stored as a hash on your server, but it will appear in the WhatsApp command message you send.
Controller PIN: Not set. Keep this channel on a separate trusted number. Anyone with both that number and PIN could request the permitted actions.

Available secure actions

Send these from your approved controller phone to the bot's WhatsApp number.

/do YOUR_PIN status /do YOUR_PIN pause /do YOUR_PIN resume /do YOUR_PIN email recipient@example.com | Subject | Message

The controller may email only addresses you add here.

Email commands only work after outgoing mail is configured. No arbitrary code execution, unrestricted forwarding, or access to other WhatsApp chats is allowed.

Add controller numbers and approved emails, then save the controller settings.
